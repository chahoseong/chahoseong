# 안녕하세요. 게임 프로그래머 차호성입니다. 👋
4년간 Unity 기반 상용 프로젝트에서 게임플레이, 에디터 커스터마이징 및 유틸리티 툴 그리고 빌드 파이프라인을 개발하며 다양한 직군과 협업을 하며 요구사항을 기술적으로 해결하는 경험을 쌓았습니다.

현재는 Unreal Engine 5로 Gameplay Ability System, Dedicated Server 구조를 활용한 멀티플레이어 액션 RPG 프로젝트를 진행하고 있습니다.

저는 문제를 해결하는 단순하고 직관적인 코드를 지향하며,
동시에 변화에 대응할 수 있는 확장 가능한 구조를 설계하려고 합니다. 매일 조금씩 배우고 개선하며, 사람들에게 흥미로운 게임플레이 경험을 전달할 수 있는 실용적인 시스템을 만드는 개발자가 되고자 합니다.

## 🧩 기술 스택

### 🎮 게임 엔진
- **언리얼 엔진**
    - Gameplay Ability System을 활용한 전투 시스템 구현
    - Dedicated Server 기반 멀티플레이 환경 구현
    - Animation System (Motion Warping, Linked Anim Layers) 활용
    - UObject 기반 데이터 중심 장비 시스템 구축

- **유니티**
    - Zenject를 활용한 의존성 관리
    - UniRx를 활용한 이벤트 기반 프로그래밍
    - UniTask를 활용한 비동기 프로그래밍
    - Addressables, Cinemachine 등 라이브러리 활용
    - 게임플레이, 에디터 툴 구현
